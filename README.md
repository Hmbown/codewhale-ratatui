# codewhale-ratatui

Build Codewhale's terminal interface from one set of components.

`codewhale-ratatui` gives [ratatui](https://ratatui.rs) apps the Codewhale
design language: the same colour roles as the Codewhale desktop app and
website, components that stay readable in 16-colour and `NO_COLOR` terminals,
and quiet motion that respects reduced-motion settings.

Status: under construction. The first release ships the theme, the settings
components and the component gallery.
